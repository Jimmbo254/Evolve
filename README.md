# EVOLVE 🏋️‍♂️💪

> **"Entrena. Progresa. Evoluciona."**

**EVOLVE** es una aplicación móvil nativa diseñada para optimizar, estructurar y dar un seguimiento preciso a los entrenamientos de cualquier deportista o aficionado al fitness. Este proyecto surge como parte del Integrador para la materia de **Desarrollo Movil Nativo** en la Licenciatura en Ingeniería en Software de la **Universidad Autónoma de Sinaloa (UAS - Facultad de Ingeniería Mochis)**.

## 📌 Problemática y Solución

### El Problema

Muchas personas al comenzar a ejercitarse —o incluso quienes llevan tiempo en ello— se enfrentan a dificultades clave:

* **Falta de estructura:** Dificultad para organizar rutinas efectivas y evitar entrenamientos o "volumen basura" (ejercicios redundantes).

* **Falta de seguimiento de la Sobrecarga Progresiva:** Muchos usuarios llevan su registro en notas del celular, papel o simplemente intentan recordar de memoria los pesos, series y repeticiones. Esto provoca estancamiento.

* **Técnica deficiente:** Dudas constantes sobre la ejecución correcta de cada ejercicio.

* **Desorganización:** Rutinas dispersas en distintas fuentes sin un historial claro de evolución.

### La Solución con EVOLVE

EVOLVE resuelve estas deficiencias proporcionando un entorno intuitivo e interactivo para:

1. **Organizar y estructurar** rutinas personalizadas.

2. **Registrar de forma inmediata** cada sesión de entrenamiento (pesos, series, repeticiones).

3. **Visualizar el progreso** a través de gráficas e indicadores de volumen.

4. **Consultar técnicas correctas** mediante guías visuales (imágenes y GIFs).

## 🚀 Funcionalidades Principales

* **Gestión de Rutinas:** Creación, edición y consulta de rutinas clasificadas (e.g., *Leg Day*, *Upper Body*, *Full Body*, *Cardio*).

* **Registro de Entrenamiento (*Log Workout*):** Interfaz para capturar el rendimiento en tiempo real (pesos en kg/lbs, repeticiones y series) por cada ejercicio.

* **Seguimiento de Sobrecarga Progresiva:** Gráficas de evolución (*Weight vs. Time*) e historial detallado de sesiones anteriores.

* **Métricas de Frecuencia:** Gráficos de entrenamientos realizados por semana (*Workouts Per Week*).

* **Guía de Técnica y Ejecución:** Biblioteca de ejercicios integrada con imágenes y GIFs demostrativos para evitar lesiones y mejorar la postura.

* **Control de Volumen Basura:** Herramientas diseñadas para mantener entrenamientos eficientes y balanceados.

## 🛠️ Tecnologías Utilizadas

* **Plataforma Target:** Aplicación Móvil Nativa (Android / iOS)

* **Lenguaje / Framework Principal:** Kotlin (Android Studio)

* **Control de Versiones:** Git & GitHub
